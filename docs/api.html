API gezgini

Bu tanım çalışan uygulamadan alınmış bir kopya (openapi.json). Uç noktaları, parametreleri ve şemaları buradan inceleyebilirsiniz. "Try it out" istekleri http://127.0.0.1:8081 adresine gider; denemek için uygulamayı yerelde açın ve bu sitenin adresini ALLOWED_ORIGINS listesine ekleyin. Yoksa tarayıcı CORS nedeniyle isteği engeller.
